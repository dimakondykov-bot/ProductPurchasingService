# Backend-сервис для автоматизации покупок товаров (Product Purchasing Service)

Это готовый асинхронный REST API бэкенд-сервис, написанный на FastAPI и SQLAlchemy 2.0 для дипломного проекта. Сервис автоматизирует процессы регистрации пользователей, управления каталогом товаров и работы с корзиной покупок.

## 🚀 Основные возможности по ТЗ:
1. **Регистрация и Вход**: Умная проверка сложности паролей (мин. 8 символов, заглавная буква, спецсимволы) и номеров телефонов в формате `+7`. Авторизация работает на защищенных JWT-токенах доступа.
2. **Каталог товаров**: Обычные пользователи могут просматривать только активные товары. Администраторы имеют полные права на добавление, изменение и удаление любых товаров.
3. **Корзина покупок**: Поддерживает одновременное добавление как одного, так и нескольких товаров списком. Автоматически считает итоговую стоимость корзины за один быстрый запрос к базе данных (без проблемы N+1).

## 🛠️ Технический стек:
* **Язык**: Python 3.11+
* **Фреймворк**: FastAPI
* **База данных**: PostgreSQL (в Docker)
* **ORM (Связь с БД)**: SQLAlchemy 2.0 (асинхронный режим Asyncpg)
* **Шифрование паролей**: Passlib
* **Тестирование**: Pytest + Pytest-asyncio + Счетчик покрытия Pytest-cov

## 💻 Инструкция по запуску проекта для комиссии:

### Вариант 1: Быстрый запуск одной кнопкой через Docker
Убедитесь, что у вас запущен Docker Desktop, и введите в терминале команду:
```bash
docker-compose up --build
```
После этого бэкенд автоматически свяжется с базой данных PostgreSQL, создаст все таблицы и запустится на порту `8000`.

### Вариант 2: Запуск тестов и замер покрытия (Пункт 10 ТЗ)
Чтобы проверить работоспособность кода и убедиться, что тесты покрывают более 75% проекта, запустите команду:
```bash
python -m pytest --cov=src --cov=main
```
